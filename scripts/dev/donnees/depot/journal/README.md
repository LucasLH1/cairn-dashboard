# Journal des sessions (données fictives)

Une entrée par session de travail, nommée `AAAA-MM-JJ-HHMM-sujet.md`, ouverte par un en-tête YAML.
Le bloc ci-dessous est un **exemple** : le dashboard ne doit pas le prendre pour une entrée.

```yaml
---
date: 2026-09-15 22:16
objectif: Exemple d'en-tête, qui n'est pas une session.
modules: ["0.1"]
issues: [1]
---
```
