# 0.2 — Catalogue articles

> Spécification **fictive**, pour le développement local du dashboard.

## 1. Objet

Décrire les articles que les donneurs d'ordre confient au prestataire, et ce qui les identifie.

## 2. Règles de gestion

- **RG-CAT-001** — Un article appartient à un seul donneur d'ordre.
- **RG-CAT-002** — Un article porte un code unique chez son donneur d'ordre, jamais globalement.
- **RG-CAT-003** — Un article déclare son unité de stockage : pièce, carton ou palette.
- **RG-CAT-004** — Un article peut porter plusieurs codes-barres ; chacun désigne une unité.

## 3. Exemple

Un même code d'article chez deux donneurs d'ordre désigne deux articles distincts :

| Donneur d'ordre | Code | Désignation |
|---|---|---|
| Exemple Sud | `ART-0042` | Lampe de bureau, blanche |
| Exemple Nord | `ART-0042` | Tabouret pliant |

## 4. Points ouverts

- Un article peut-il changer d'unité de stockage en cours de vie ? (issue #21)
