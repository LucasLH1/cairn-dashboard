# 0.3 — Adressage des emplacements

> Spécification **fictive**, pour le développement local du dashboard.

## 1. Objet

Donner à chaque emplacement une adresse lisible, stable et unique dans son site.

## 2. Masque d'adresse

L'adresse se compose selon le masque du site. Le masque par défaut est :

```
<allée>-<colonne>-<niveau>-<position>
A-03-2-B
```

- **RG-ADR-001** — Une adresse est unique dans son site.
- **RG-ADR-002** — Le masque se déclare par zone logistique, et hérite de celui du site à défaut.
- **RG-ADR-003** — Une adresse ne se réemploie pas pendant douze mois après la suppression de son
  emplacement.
- **RG-ADR-004** — Une allée sans emplacement reste déclarée ; elle apparaît vide sur le plan.

## 3. Cas limites

1. **Mezzanine** : le niveau porte la lettre `M` suivie du numéro, par exemple `C-12-M1-A`.
2. **Emplacement de sol** : le niveau vaut `0`, la position est omise.
