# 0.4 — Unités logistiques

> Spécification **fictive**, pour le développement local du dashboard.

## Règles de gestion

- **RG-ULO-001** — Une unité logistique porte un identifiant unique, imprimé sur une étiquette.
- **RG-ULO-002** — Une unité logistique se trouve à un seul emplacement à la fois.
- **RG-ULO-003** — Une unité logistique peut en contenir d'autres, sur un seul niveau d'imbrication.
